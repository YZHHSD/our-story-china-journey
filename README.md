# 我们的故事

双人旅行网站的静态试用版，使用原生 HTML、CSS 和 JavaScript，无需构建步骤。

## 本地预览

在本目录启动任意静态文件服务器，然后打开 `index.html`。页面的 CSS 与 JavaScript 使用相对路径，适用于 GitHub Pages 的项目子路径。

## 数据说明

旅行日志、收藏、投票、照片和计划保存在当前浏览器的 `localStorage`。点击网站里的“导出备份”可以保存 JSON。GitHub Pages 不提供此版本所需的双人账号与跨设备同步功能。

地图当前是地点分布示意，景点数据用于展示和记录。具体交通、门票、开放时间与预算请在出发前核对。
